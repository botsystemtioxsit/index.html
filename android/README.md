# Тролль-Баттл — Android

Минимальное Android-приложение: одно `WebView`, открывающее ту же живую
игру, что и браузерная версия и десктоп-приложение в `../desktop/`.
Никакой отдельной копии игры внутри — значит, любое обновление игры
долетает сюда само, без пересборки APK.

Игра — голосовой баттл, поэтому приложение просит доступ к микрофону
(`RECORD_AUDIO`) при первом запросе со страницы — обычный системный
диалог Android, без него звук не заработает.

Вход внутри работает как обычно (гость, email/Telegram ID или токен
доступа — см. `resolveIdentity()` в `src/index.html`) — ничего
специального для Android-версии настраивать не нужно.

## Сборка

Собирается через GitHub Actions (Android SDK + Gradle не нужны локально):
вкладка **Actions** → **Build Android APK** → **Run workflow**, либо
автоматически при любом пуше, который трогает `android/`. Готовый
`app-debug.apk` публикуется как вложение к GitHub Release этого репозитория
под фиксированным тегом `android-latest` — ссылка не меняется между
сборками.

Это debug-сборка (не для Google Play), подписанная постоянным ключом — см.
«Подпись APK» ниже. Этого достаточно, чтобы установить APK на телефон
напрямую. При установке Android спросит разрешить «Установка из неизвестных
источников» — это нормально для APK не из Google Play.

## Подпись APK

Google Play Защита блокирует установку со словами «никогда не проверяла
приложение этого разработчика», если APK подписан ключом, которого она
ещё не видела. Раньше CI при каждой сборке создавал **новый случайный
отладочный ключ** — поэтому каждая версия выглядела как приложение от
нового разработчика, а поверх предыдущей версии она вообще не
устанавливалась (подпись не совпадает — Android просит сначала удалить
старое приложение, а с ним и его данные).

Теперь APK подписывается **постоянным ключом**. Это один и тот же ключ в
обоих репозиториях — `index.html` (игра) и `battle-admin-bot` (панель),
поэтому для Google это один и тот же разработчик. Сам файл ключа лежит в
секретах GitHub (**Settings → Secrets and variables → Actions → New
repository secret**), в имени `ANDROID_KEYSTORE_BASE64`. Пароль (`battle-android`) и
алиас (`battle`) не секретны — они вшиты в workflow: секретен сам файл.

- Секрета нет — сборка идёт как раньше, одноразовым отладочным ключом, в
  логе жёлтое предупреждение. Ничего не ломается, но предупреждение Play
  Защиты и невозможность обновиться поверх остаются.
- Секрет есть — в логе шага **Show signing certificate** виден отпечаток
  сертификата, он должен быть **одним и тем же** от сборки к сборке.
- **Ключ нельзя терять и нельзя менять:** с новым ключом Android снова
  откажется ставить APK поверх старого. Копию текста секрета стоит хранить
  в надёжном месте (например, «Избранное» в Telegram).
- Ключ не должен попадать в репозиторий: репозиторий публичный, а значит любой мог бы
  подписать «обновление» с вашим именем пакета.

При первом переходе со старого (отладочного) ключа на постоянный Android не
поставит новую сборку поверх установленной — старое приложение надо один раз
удалить. Дальше обновления ставятся поверх. Предупреждение Play Защиты при
самой первой установке всё равно может появиться (ссылка «Все равно
установить» внизу диалога) — после неё Google уже знает этот сертификат.

## Значок приложения

Красная звезда на тёмном фоне. Исходник — квадрат 2000×2000; из него нарезаны
`desktop/icon.png` (512×512, для Windows/Linux) и значки Android во всех
плотностях `app/src/main/res/mipmap-*/` (48/72/96/144/192 px): `ic_launcher.png`
со скруглёнными углами и `ic_launcher_round.png` кругом. Чтобы заменить —
подготовьте новый квадрат и перенарежьте в те же файлы.
